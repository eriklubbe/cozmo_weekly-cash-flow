Shared storage on GitHub

How to get a token

Each person uses their own token, so the commit history shows who changed what. The token is kept in this browser only.

  1. Repo owner: GitHub › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate. Repository access: Only select repositories › this repo. Permissions › Repository › Contents: Read and write.
  2. Anyone else: the owner adds them under the repo's Settings › Collaborators. Fine-grained tokens can't reach a repo owned by another personal account, so they create a classic token with the repo scope (or move the repo into a GitHub organisation and use fine-grained tokens).
  3. For view-only access, give the token read-only Contents permission — the app then opens in view mode.

Import from Xero

In Xero export outstanding invoices (Sales › Invoices › Awaiting payment › Export) and bills (Purchases › Bills › Awaiting payment › Export) as CSV, or export the Aged Receivables / Payables Detail report as Excel or CSV. Any file with contact, invoice number, due date and amount columns works — you can pick the columns below. Re-importing replaces the previous import of that type but keeps any dates you moved.

Password access

People then open the app and enter the password; they don't need a GitHub account. Your GitHub token is saved in the repo (docs/access.js) encrypted with this password, and their changes are committed under your account. The forecast itself stays readable on GitHub. Change the password when someone should lose access — to cut off a browser that is already signed in, also replace your GitHub token and set the password again.

Payment timing rules

Shift every invoice or bill for a customer or supplier by a fixed time from its due date — e.g. a supplier you always pay two months late. Rules also apply to future imports; dragging an item still overrides its rule.
