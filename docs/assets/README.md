# Brand assets

Cozmo has no logo file here yet, so the header shows the cozmo wordmark as
text. To use the real logo, add it here (e.g. `logo.svg` or a transparent
`logo.png`) and set `logo: 'assets/logo.svg'` in `config.js`. The round "C"
stamp emblem can be added the same way as `badge` for the password screen and
browser tab.
